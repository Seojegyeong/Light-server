## 항목별 비교

| 용어 | 기준 | Before | After |
|---|---|---|---|
| 스태그플레이션 | 쉬운가 | ❌ "인플레이션", "악순환" | ✅ 괄호로 풀이 추가 |
| 스태그플레이션 | 형식 | ❌ "~입니다" / 용어명 반복 | ✅ 명사형 / 반복 없음 |
| 양적긴축 | 맞는가 | ❌ 수치 지어냄 (600억/400억) | ✅ 수치 없음 |
| 양적긴축 | 쉬운가 | ❌ "모기지담보증권", "긴축 통화정책" | ✅ 전문용어 최소화 |
| 사이드카 | 맞는가 | ❌ 서킷브레이커와 혼동 ("거래 15분 중단") | ✅ "프로그램 매매 중단"으로 정확히 구분 |
| 외국인 순매도 | 쉬운가 | ❌ 2문장, 길고 용어 나열 | ✅ 1문장, 핵심만 |
| 증시 | 추출 여부 | ❌ 쉬운 말인데 추출됨 | ✅ 추출되지 않음 |
| category | 형식 | ❌ 미등록 용어 모두 null | ✅ 거시경제·주식·파생상품 분류 |
| aliases | 형식 | ❌ 미등록 용어 모두 빈 배열 | ✅ 영문명·약어 포함 |
